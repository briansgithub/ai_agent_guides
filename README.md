# AI Agent Guides

Reusable, vendor-neutral guidance packages for software repositories.

## Available kits

- [`git-handoff-system/`](git-handoff-system/) — permanent branch handoffs, append-only histories, archive lifecycle, multi-agent Git worktree isolation, agent/IDE entry points, templates, validation script, and GitHub Actions CI.

Copy a kit’s **contents** into a repository root and follow its installation README.
