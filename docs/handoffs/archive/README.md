# Archived branch handoffs

Frozen closed-form handoffs and append-only histories for inactive branches.

Path mirrors:

- `docs/handoffs/feature/foo.md` → `docs/handoffs/archive/feature/foo.md`
- `docs/handoffs/feature/foo.history.md` → `docs/handoffs/archive/feature/foo.history.md`

Freeze both at closure; later edits only correct factual errors. Append one close entry to global [HISTORY.md](../HISTORY.md).
